# Object Detection Module (Coming Soon)

This directory is reserved for real-time Object Detection tasks, such as YOLO-style (You Only Look Once) or SSD-style (Single Shot MultiBox Detector) inference systems.

### Planned Features
- Anchor-box based bounding box generation purely in CUDA.
- Non-Maximum Suppression (NMS) CUDA kernel for bounding box filtering.
- Multi-scale feature extraction for small and large object detection.
- Fast bounding box intersection and area computation kernels.
